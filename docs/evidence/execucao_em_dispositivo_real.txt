DEFEITO ENCONTRADO NA FERRAMENTA DE CAPTURA
-------------------------------------------
A tentativa de captura revelou um defeito no script
docs/store/screenshots/capturar.ps1, que foi corrigido:

  PROBLEMA : `adb exec-out screencap -p > ficheiro.png` em PowerShell produz
             um PNG CORROMPIDO. O operador `>` trata a saida como texto,
             aplica a codificacao de saida e acrescenta um BOM.

  EVIDENCIA: os primeiros bytes do ficheiro gerado eram

                 ef bb bf ef bf bd 50 4e

             quando a assinatura de um PNG valido e

                 89 50 4e 47

  CORRECCAO: passar a gravar no dispositivo e trazer o ficheiro com `adb
             pull`, que copia os bytes sem interpretacao:

                 adb shell screencap -p /sdcard/temp.png
                 adb pull /sdcard/temp.png <destino>
                 adb shell rm /sdcard/temp.png

  ACRESCENTADO: o script passou tambem a
             (a) verificar a assinatura PNG dos ficheiros gerados, apagando
                 os que nao forem imagens validas, e
             (b) acordar o ecra antes de capturar, para nao produzir imagens
                 pretas.

  NOTA PARA QUEM USAR GIT BASH: o Git Bash converte /sdcard/... num caminho
  do Windows. E preciso exportar MSYS_NO_PATHCONV=1 antes de usar o adb com
  caminhos do dispositivo. Em PowerShell esse problema nao existe.
