## 3. 完整说明（最多 4000）

```
dB Konversor 用于换算通信、电子、射频与音频工程中每天都会用到的功率单位和
对数电平。

输入数值，选择输入单位与输出单位，结果立即显示。无广告、无需注册、无需联网。


支持的单位

• dBm — 以 1 mW 为基准的功率
• dBW — 以 1 W 为基准的功率
• W — 瓦特
• mW — 毫瓦
• dBV — 以 1 V 为基准的电压电平
• dBu — 以 0.775 V 为基准的电压电平
• dB — 对数比值，相对于您所给定的参考值


可以计算什么

• dBm 与瓦特之间的双向换算
• dBm 与 dBW 之间的双向换算
• dBV 与 dBu 之间的双向换算
• 功率与电压电平之间的换算（需给定阻抗：50 Ω、75 Ω、600 Ω、8 Ω 或其他数值）
• 以任意参考值为基准的增益与损耗（dB）


公式始终可见

每个结果都附带所用公式，并包含全部中间步骤。例如从 dBm 换算到 dBV，会显示
完整的计算链：

mW = 10^(dBm / 10)  |  V = √(P × R)  |  dBV = 20 × log10(V)

正因如此，本应用不只是一个出数字的工具，更是一个学习工具。初学者可以看清推导
路径；熟练的工程师可以核对计算过程是否符合预期。


仅在必要时才要求输入阻抗

把功率换算为电压电平必须知道阻抗，因为 V = √(P × R)；而把 dBm 换算为瓦特则
不需要。本应用只在确实需要阻抗的换算中请求该参数，既不会每次都强制要求，也
不会在用户不知情的情况下默认按 50 Ω 计算。


换算记录保存在您的手机上

最近 50 条换算记录会连同日期一并保存，方便日后查阅。这些记录仅保存在您的
设备上，可随时删除，并且绝不会被发送到任何地方。


无需联网即可使用

正式发布版本甚至不申请网络访问权限。所有计算均在手机本地完成。无论是在
铁塔上、地下室、实验室还是飞机上，都可以正常使用。


适用人群

• 通信、电子与电气工程专业的学生
• 需要讲解线性标度与对数标度关系的教师
• 网络安装与维护技术人员
• 射频与通信工程师
• 音响技师与音频工程师
• 业余无线电爱好者


关于计算精度

所有换算均由一整套自动化测试覆盖，测试所用的预期值独立于被测实现推导得出。
计算采用双精度浮点数；当数值超出可表示范围时，应用会明确提示原因，而不会
返回一个可疑的结果。


支持语言

简体中文、葡萄牙语、英语、法语、西班牙语。


由 KUNDIAMA Tecnologia e Inovação 开发。
```

## 8. 差异化信息

与通用计算器相比：

> 通用计算器只换算数字。dB Konversor 清楚 dBm 与 dBV 是**两类不同的物理量**
> ——一个是功率，一个是电压——两者之间的换算必须知道阻抗。所以它只在这类
> 换算中询问阻抗，也仅限于这类换算。

与其他分贝换算工具相比：

> 它为每一次换算显示完整公式，不申请任何权限，记录保存在本地且绝不外传。

## 9. 术语说明

| 术语 | 选用译法 | 理由 |
|---|---|---|
| decibel | 分贝 | 中国大陆与新马地区通用标准译法 |
| power | 功率 | 不可译作「电力」或「能量」 |
| voltage | 电压 | — |
| level | 电平 | 通信与音频工程的标准术语；不可译作「水平」 |
| impedance | 阻抗 | — |
| reference value | 参考值 | — |
| ratio | 比值 | — |
| watt / milliwatt | 瓦特 / 毫瓦 | 正文使用中文名，**符号始终保留** `W` / `mW` |
| ohm | 欧姆 | 正文用中文，界面用 `Ω` |
| dBm、dBW、dBV、dBu | **绝不翻译** | 国际通用技术符号 |
| 小数点 | `0.775 V` | 中文使用小数点，而非逗号 |
| 顿号 `、` | 用于并列单位 | 中文标点规范：并列词语之间用顿号，而非逗号 |
